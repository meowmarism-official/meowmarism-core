# Naming

- The family is **meowmarism**.
- The products are **meowmarism LITE** and **meowmarism PROFESSIONAL**.
- In narrow places (badges, tabs, package names) PROFESSIONAL may be shortened to **PRO**. Everywhere else write it out.
- Repositories: `meowmarism-core`, `meowmarism-lite`, `meowmarism-professional`, `meowmarism-website`.
- Versions start at `0.0.0` in every repository. `1.0.0` is only used when the owner says the product is usable.
